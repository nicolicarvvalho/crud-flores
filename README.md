# 🌺 CRUD de Flores 🌺

Essa atividade foi desenvolvida durante as aulas de BackEnd aplicando os conceitos de **Programação Orientada a Objetos (POO)** em **PHP** com integração ao banco de dados **PostgreSQL**.

## 🌷 Sobre o projeto

Sistema CRUD completo para gerenciamento de flores, contemplando as operações básicas:
- 🌸 **Create:** Cadastro de novos registros
- 🌻 **Read:** Listagem dos dados cadastrados
- 🌹 **Update:** Edição de informações
- 🌼 **Delete:** Exclusão de registros

## 🪻 Tecnologias utilizadas

- **PHP** 
- **PostgreSQL**
- **HTML & CSS**
